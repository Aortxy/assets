# Laporan Pengumpulan Aset Poster Vertikal UI

Proyek pengumpulan aset visual ini bertujuan untuk menyediakan koleksi gambar sampul vertikal yang beragam dan berkualitas tinggi guna memenuhi kebutuhan antarmuka pengguna (UI) pada aplikasi Anda. Sebanyak 25 poster unik telah berhasil dikumpulkan dari sumber-sumber resmi yang diminta, mencakup kategori anime, manga, manhwa, manhua, dan web novel tanpa ada duplikasi judul.

## Catatan Implementasi Teknis

Seluruh file gambar telah melalui proses verifikasi orientasi untuk memastikan bentuk vertikal yang proporsional sehingga siap diintegrasikan langsung ke dalam tata letak UI aplikasi Anda. Untuk memudahkan distribusi dan penyalinan aset ke lingkungan pengembangan proyek Anda, seluruh file gambar beserta dokumentasi ini telah dikompresi ke dalam arsip tunggal bernama `posters_ui.zip` pada direktori utama sandbox.
